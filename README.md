# 旅游小助手 Travel Assistant Skill

一个温暖贴心的AI旅游规划助手，帮助用户智能规划旅行并生成可爱的旅行建议卡片。

## ✨ 核心特性

- 🗣️ **温暖对话式引导**：不是冷冰冰的问卷，而是像朋友聊天一样收集信息
- 🧠 **多维度智能分析**：考虑时间、目的地、人群、场景等多个维度
- 📝 **精简建议输出**：每条建议不超过15字，简洁实用
- 🎨 **可爱卡通图片**：生成手绘蜡笔风格的旅行建议卡片，可保存打印
- 💝 **情绪价值满满**：预判焦虑、给予安全感、细节关怀

## 📋 功能说明

### 信息收集
- 出行时间、目的地、出发地、旅行天数
- 人员构成（婴幼儿/儿童/青少年/成年人/老年人）
- 出行方式、特殊需求、预算范围

### 智能分析
- **时间维度**：节假日拥堵预警、季节特点、当地节庆
- **目的地维度**：气候特征、海拔高度、文化禁忌、医疗资源
- **人群适配**：婴儿/儿童/老人/孕妇的特殊需求
- **场景细节**：海边/山区/城市/自驾的装备建议

### 输出内容
生成三个板块的精简建议：
1. 📌 **注意事项**（3-5条）
2. 🎒 **必带物品**（3-5条）
3. 💝 **贴心提示**（3-5条）

最终生成可爱的卡通风格旅行卡片图片。

## 🚀 使用方法

### 在 Claude Code 中使用
```bash
# 将 travel-assistant.md 放到项目的 .claude/skills/ 目录
mkdir -p .claude/skills
cp travel-assistant.md .claude/skills/

# 调用skill
/travel-assistant
```

### 在其他AI平台使用

**Codex / Workbuddy / 其他支持自定义指令的平台**：
1. 复制 `travel-assistant.md` 的全部内容
2. 作为系统提示词或自定义指令加载
3. 开始对话即可使用

**注意**：不同平台对skill的加载方式可能不同，请根据平台文档调整。

## 🛠️ 依赖说明

### 推荐工具（可选）
- **WebSearch**：用于获取实时天气、节假日信息
- **图像生成工具**：DALL-E、Midjourney或其他AI绘图服务

**如果没有这些工具**：skill会自动降级，基于常识给出建议，并提供生图提示词供用户手动生成图片。

## 📖 使用示例

### 示例对话

**用户**：我想国庆带孩子去三亚

**助手**：好期待！三亚的海滩孩子一定会喜欢~ 
- 孩子多大呀？
- 打算玩几天呢？
- 从哪里出发？

**用户**：5岁男孩，从北京出发，玩5天

**助手**：明白啦！5岁正是爱玩水的年纪~
- 你们是飞机过去吗？
- 还有其他家人一起吗？
- 孩子有没有特别要注意的？

*（收集完信息后生成建议和卡片图片）*

### 生成的建议示例

**国庆三亚亲子游建议**

📌 **注意事项**
- 国庆人流高峰，提前订票
- 紫外线强，防晒要做足
- 海边风大，备件薄外套

🎒 **必带物品**
- 儿童防晒霜SPF50+
- 泳衣泳圈救生衣
- 防蚊液和晒后修复

💝 **贴心提示**
- 给宝贝带个沙滩玩具
- 准备小零食应对排队
- 拍照别忘备用充电宝

## 🎨 图片风格

生成的旅行卡片特点：
- 可爱卡通手绘蜡笔质感
- 色彩柔和温暖（粉色、浅蓝、薄荷绿、暖黄）
- 排版有节奏、留白充足
- 适合保存到手机或打印

## 🔧 自定义

你可以根据需要修改 `travel-assistant.md` 中的：
- 建议条数（默认3-5条）
- 文字长度限制（默认15字）
- 图片风格描述
- 分析维度的优先级
